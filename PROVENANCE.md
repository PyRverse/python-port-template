# Provenance record

## Current scaffold

This repository contains original packaging, documentation, and a small arithmetic
teaching example. It includes no upstream R package source or datasets. The
reference fixture is hand-calculated and is not evidence of R/Python parity.
The scaffold is MIT-licensed; future ports require their own recorded review.

## Complete for each actual port

| Field | Evidence to record |
| --- | --- |
| Method and scope | Exact supported behavior and explicit exclusions |
| Original authors and citations | Verified source links and citation metadata |
| Upstream source | Package, version, revision, and archive/checksum |
| Upstream license | Exact license and bundled notices at that revision |
| Implementation approach | Translation, independent implementation, or mixed; explain |
| Source consulted or reused | Files, snippets, documentation, and modifications |
| Dependencies and bundled material | Licenses and required attribution |
| Data provenance | Source, license, consent/access restrictions, checksums |
| Reference generation | Script, command, R session, seed, output checksums |
| Numerical validation | Tolerances, rationale, tested scope, known differences |
| Distribution license decision | Compatibility rationale and notices retained |
| Review | Real reviewer, date, unresolved questions, and approval evidence |

Unfilled fields mean review is incomplete; do not replace them with assumed
author endorsements or unverified compatibility claims.
