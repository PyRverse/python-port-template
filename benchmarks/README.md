# Benchmarks

Run `python benchmarks/benchmark_example.py` from the repository root after
installation. It prints JSON with five local timing samples and environment
details. Timings are intentionally outside CI and are not committed as results.

For a real method, document input generation, realistic sizes, warm-up, hardware,
thread counts, dependencies, and memory measurements. Compare accuracy before
performance. Do not infer general speedups from this illustrative function.
